# MediReminder AI Backend API

Production-ready Node.js Express backend for the medicine reminder platform **MediReminder AI**.

## Technology Stack

- **Framework**: Express.js (Node.js)
- **Database**: PostgreSQL (Supabase)
- **Storage**: Supabase Storage Buckets
- **AI Engine**: Google Gemini Pro (`gemini-1.5-flash` for multimodal OCR and reviews)
- **Authentication**: JWT, Mobile OTP, Google/Apple OAuth 2.0
- **Push Engine**: Firebase Cloud Messaging (FCM)
- **Payments**: PayU Payment Gateway
- **Documentation**: Swagger UI / OpenAPI 3.0
- **Scheduler**: Node-Cron Daemon
- **Logger**: Winston Logging (Console + file rotation logs)

## Local Setup & Installation

### 1. Prerequisites
- **Node.js**: `v18.0.0` or higher
- **PostgreSQL Database** (You can use local Postgres or a free database instance on Supabase)

### 2. Install Dependencies
Navigate to the backend directory and run:
```bash
npm install
```

### 3. Environment Configuration
Duplicate the example environment file and rename it to `.env`:
```bash
cp .env.example .env
```
Open `.env` and fill in your connection strings and API keys:
- Add your database connection string in `DATABASE_URL`.
- Generate a secure key for `JWT_SECRET`.
- Fill in `SUPABASE_URL` and `SUPABASE_ANON_KEY`.
- Provide a `GEMINI_API_KEY` for AI features (OCR, Safety review).
- Add Firebase credentials for push alerts.
- Insert PayU sandbox keys for checkout features.

### 4. Run Database Migrations
Run the initial SQL schema script on your database instance:
- If using Supabase, navigate to the **SQL Editor** in the Supabase Dashboard, click **New query**, paste the contents of the migration file located at: `migrations/001_initial_schema.sql`, and click **Run**.
- If using raw PostgreSQL command line tools:
  ```bash
  psql -U username -d dbname -f migrations/001_initial_schema.sql
  ```

### 5. Running the Application
To run the server locally in development mode (with hot-reloading via `nodemon`):
```bash
npm run dev
```

To run the server in production mode:
```bash
npm start
```

## Render Deployment Instructions

This project is fully structured for cloud deployments on **Render**:

### Step 1: Create a Web Service
1. Log into your [Render Dashboard](https://dashboard.render.com).
2. Click **New +** and select **Web Service**.
3. Link your GitHub repository and select the repository branch.
4. Set the **Root Directory** option to:
   ```text
   backend
   ```

### Step 2: Configure Build and Start Commands
- **Runtime**: `Node`
- **Build Command**:
  ```text
  npm install
  ```
- **Start Command**:
  ```text
  node src/server.js
  ```

### Step 3: Configure Environment Variables
Navigate to the **Environment** tab in your Web Service dashboard and insert variables:
- `PORT`: `3000`
- `NODE_ENV`: `production`
- `DATABASE_URL`: *Your Supabase PostgreSQL pooling connection string*
- `JWT_SECRET`: *A secure random string*
- `SUPABASE_URL`: *Your Supabase Project URL*
- `SUPABASE_ANON_KEY`: *Your Supabase Anon API key*
- `GEMINI_API_KEY`: *Your Google Gemini API key*
- `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY` (Ensure private key handles newlines `\\n`)
- `PAYU_MERCHANT_KEY`, `PAYU_MERCHANT_SALT`, `PAYU_BASE_URL` (Use Sandbox or Production URL)
- `APP_URL`: *The public URL generated by Render for your Web Service*
